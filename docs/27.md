### プロジェクト27：デジタルIRレシーバーモジュール
![image318](media/501e7b6e850b46f6673b6fe2732e1ed9.png)

**説明**

![image319](media/e3072e28476494001a517d9da290eba7.png) KY-022赤外線レシーバーモジュールは38kHzのIR光に反応します。テレビ、ステレオ、その他のデバイスのIRリモートコントローラーからのコマンドを受信するために使用できます。

[KY-005 IRトランスミッターモジュール](https://arduinomodules.info/ky-005-infrared-transmitter-sensor-module/)と組み合わせて使用することもできます。

IRはリモートコントロールで広く使用されています。このIRレシーバーを使用すると、適切なデコーダーがあれば、Arduinoプロジェクトは任意のIRリモートコントローラーからコマンドを受信できます。また、IRトランスミッターを使用して独自のIRコントローラーを簡単に作成することもできます。

**仕様**

| 動作電圧         | 2.7V〜5.5V     |
|------------------|----------------|
| 動作電流         | 0.4mA〜1.5mA   |
| 受信距離         | 18m            |
| 受信角度         | ±45º           |
| キャリア周波数   | 38KHz          |
| 低レベル電圧     | 0.4V           |
| 高レベル電圧     | 4.5V           |
| 周囲光フィルター | 最大500LUX     |

**赤外線とは？**

赤外線放射は、私たちの周りにある光と同様の光の一種です。IR光と可視光の唯一の違いは周波数と波長であり、赤外線は可視光の範囲外にあるため、人間の目には見えません。赤外線を見る良い方法は、古いカメラを通して見ることです。これは、古いカメラにはIR光を可視にするフィルターが含まれており、通常は紫色の光として見られるためです。

![image320](media/7af21783ad7da58fd6407715d62ef29f.png)

**IR信号変調**

IR光は太陽、電球、その他熱を発生するものから放出され、私たちの周りに常に存在します。そのため、IRレシーバーが送信機から送られるIR放射ではなく、この余分なIR放射をすべて拾ってしまうと考えるのは簡単でしょう。この余分な放射がIR信号に干渉するのを防ぐために、信号変調技術が使用されます。

IR信号変調では、IRリモートのエンコーダーがバイナリ信号を変調された電気信号に変換します。この電気信号は送信LEDに送られます。送信LEDは変調された電気信号を変調されたIR光信号に変換します。IRレシーバーはIR光信号を復調し、バイナリに戻してから、以下の図に示すようにマイクロコントローラーに情報を渡します。

![image321](media/646dc5df108dd64a06290f608fb3ba32.png)

変調されたIR信号は、高周波数でオンオフが切り替わる一連の光パルスであり、これはキャリア周波数として知られています。ほとんどの送信機で使用されるキャリア周波数は38 kHzです。これは自然界ではまれであるため、周囲のIRノイズと区別できるためです。このようにして、IRレシーバーは38 kHz信号が送信機から送信されたものであり、周囲の環境から拾われたものではないことを認識します。

ピン配置

![image322](media/4facfbb2b8b032da47bd98e65b00a8e1.png)

SINは、Arduinoに接続するIRレシーバーモジュールの信号ピンです。

VCCはArduinoの+5V電源に接続する必要があります。

GNDはArduinoのグランドに接続する必要があります。

**接続図**

モジュールの電源線（中央）とグランド（-）をそれぞれArduinoの+5とGNDに接続します。また、信号ピン（S）をピン11に接続します。IRレシーバーとトランスミッターを向かい合わせに配置します。
