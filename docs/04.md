### Project 4: SMD RGB LED Module
![image88](media/e292bc519a648de5d1372b7ea9b683e7.png)

**説明**

![image89](media/92b275d57646ec52b34d0d99ff3973d7.png)これはフルカラーLEDモジュールで、赤（Red）、緑（Green）、青（Blue）の3色を内蔵しています。各色は個別のLEDとして扱えます。

プログラムによって順番に点灯／消灯したり、PWMアナログ出力を使って3色を混ぜることで様々な色を生成できます。

**仕様**

| Operating Voltage                                       | 5V max Red 1.8V ~2.4V Green 2.8V ~ 3.6V Blue 2.8V ~ 3.6V |     |
|---------------------------------------------------------|----------------------------------------------------------|-----|
| Forward Current                                         | 20mA ~ 30mA                                              |     |
| Operating Temperature                                   | -25°C to 85°C \[-13°F ~ 185°F\]                          |     |
| Board Dimensions \| 18.5mm x 15mm \[0.728in x 0.591in\] |                                                          |     |

**仕組み**

SMD LED（SMDは Surface-Mount-Device、LEDは Light-Emitting-Diode の略）は、3in1のパッケージに赤・緑・青の3色を統合したタイプのLEDです。

![image90](media/6035fa175ff13175441d6e9d917835f1.png)

![image91](media/3283bb2942b7192c09b3b60eed9b2f09.png)

このタイプのモジュールは4つのピンで構成されています：GND（グラウンド）ピン、Red、Green、Blueの各ピンです。

これら3つのピンはデジタル信号で、任意のマイコンボードのデジタルポートに接続します。本プロジェクトでは Arduino Uno を使用しています。

接続してコードを書き込むと、チップ内部のLEDが点灯します。

![image92](media/8b4df51d3b534dc95986dc10754ed541.jpeg)

信号ピンの各所に抵抗を配置して電流を制御し、モジュールが焼損するのを防ぎます。

Pinout

![image93](media/7eea528e8752005f62e8d372f0ce2071.png)

GREEN は Arduino に接続する緑色LEDのピンです。

RED は Arduino に接続する赤色LEDのピンです。

BLUE は Arduino に接続する青色LEDのピンです。

GND は Arduino のグラウンドに接続してください。

**接続図**

赤ピン（R）を Pin 10、緑ピン（G）を Pin 11、青ピン（B）を Pin 9、最後にグラウンドピン（-）を GND に接続します。

LEDの焼損を防ぐため、ボードと Arduino の間に必ず抵抗を挿入してください。
