### Projekt 5: Aktives Summer-Modul
![image97](media/ea727c6d18d08e6ac756f76b11698724.png)

**Beschreibung**

![image98](media/238b0ea29901d6cf1e09b99f5297b5d3.png) Das aktive Summer-Modul ist das einfachste Modul zur Klangerzeugung. Sie können es mit einem High/Low-Pegel ansteuern.

Dieses Modul wird häufig in unseren täglichen Geräten wie PCs, Kühlschränken, Telefonen usw. verwendet.

Darüber hinaus können Sie mit diesem kleinen, aber nützlichen Modul viele interessante interaktive Projekte erstellen. Probieren Sie es einfach aus! Sie werden den elektronischen Klang, den es erzeugt, faszinierend finden.

**Spezifikation**

| Betriebsspannung | 3.5V ~ 5.5V |
|------------------|-------------------------------------|
| Maximaler Strom | 30mA / 5VDC |
| Resonanzfrequenz | 2500Hz ± 300Hz |
| Minimaler Schalldruck | 85Db @ 10cm |
| Arbeitstemperatur | -20°C ~ 70°C \[-4°F ~ 158°F\] |
| Lagertemperatur | -30°C ~ 105°C \[-22°F ~ 221°F\] |
| Platinenabmessungen | 18.5mm x 15mm \[0.728in x 0.591in\] |

**Wie funktioniert es?**

![image99](media/bbc52b600c70618e83a69bfee9fdbe16.png)Der aktive Summer, auch als Indikatorsummer bekannt, verwendet Gleichstrom und erzeugt dank seiner eingebauten Platine sofort eine Frequenz, wenn er mit Strom versorgt wird. Er hat jedoch nur eine Frequenz und kann gepulst werden. Er erzeugt einen Ton von ungefähr 2,5 kHz, wenn das Signal hoch ist.

Pinbelegung

![image100](media/ef8376d23e540d86886923ec5c5425c2.png)

SIN ist der Pin des aktiven Summers, den wir mit dem Arduino verbinden.

NC bedeutet, dass nichts angeschlossen wird.

GND sollte mit der Masse des Arduino verbunden werden.

**Verbindungsdiagramm**

Verbinden Sie das Signal (S) mit Pin 8 am Arduino und Masse (-) mit GND. Der mittlere Pin wird nicht verwendet.

| **KY-012** | **Arduino** |
|------------|-------------|
| S Mitte | Pin 8 |
| – | GND |
