### プロジェクト 5: アクティブブザーモジュール
![image97](media/ea727c6d18d08e6ac756f76b11698724.png)

**説明**

![image98](media/238b0ea29901d6cf1e09b99f5297b5d3.png) アクティブブザーは、最もシンプルな音出しモジュールです。ハイ/ローレベルで駆動できます。

このモジュールは、PC、冷蔵庫、電話など、私たちの日常の電化製品で広く使用されています。

さらに、この小さくても便利なモジュールで、多くの興味深いインタラクティブなプロジェクトを作成できます。ぜひ試してみてください！それが生み出す電子音はとても魅力的だと感じるでしょう。

**仕様**

| 動作電圧 | 3.5V ~ 5.5V |
|----------|-------------------------------------|
| 最大電流 | 30mA / 5VDC |
| 共振周波数 | 2500Hz ± 300Hz |
| 最小音出力 | 85Db @ 10cm |
| 動作温度 | -20°C ~ 70°C \[-4°F ~ 158°F\] |
| 保存温度 | -30°C ~ 105°C \[-22°F ~ 221°F\] |
| 基板寸法 | 18.5mm x 15mm \[0.728in x 0.591in\] |

**動作原理**

![image99](media/bbc52b600c70618e83a69bfee9fdbe16.png)アクティブブザーは、インジケーターブザーとも呼ばれ、DC電源を使用し、内蔵のPCBにより電源が供給されるとすぐに周波数を生成します。ただし、周波数は1つだけで、パルス化することができます。信号がハイの場合、約2.5kHzの音を生成します。

ピン配置

![image100](media/ef8376d23e540d86886923ec5c5425c2.png)

SINは、Arduinoに接続するアクティブブザーのピンです。

NCは何も接続しないことを意味します。

GNDはArduinoのGNDに接続する必要があります。

**接続図**

信号 (S) をArduinoのPin 8に、GND (-) をGNDに接続します。中央のピンは使用しません。

| **KY-012** | **Arduino** |
|------------|-------------|
| S 中央 | Pin 8 |
| – | GND |
