### Projet 5 : Module de buzzer actif
![image97](media/ea727c6d18d08e6ac756f76b11698724.png)

**Description**

![image98](media/238b0ea29901d6cf1e09b99f5297b5d3.png) Le buzzer actif est le module de production sonore le plus simple. Vous pouvez l'activer avec un niveau haut/bas.

Ce module est largement utilisé dans nos appareils quotidiens comme les PC, les réfrigérateurs, les téléphones, etc.

De plus, vous pouvez créer de nombreux projets interactifs intéressants avec ce petit mais utile module. Essayez-le ! Vous trouverez le son électronique qu'il crée si fascinant.

**Spécification**

| Tension de fonctionnement | 3.5V ~ 5.5V |
|---------------------------|-------------------------------------|
| Courant maximal | 30mA / 5VDC |
| Fréquence de résonance | 2500Hz ± 300Hz |
| Sortie sonore minimale | 85Db @ 10cm |
| Température de fonctionnement | -20°C ~ 70°C \[-4°F ~ 158°F\] |
| Température de stockage | -30°C ~ 105°C \[-22°F ~ 221°F\] |
| Dimensions de la carte | 18.5mm x 15mm \[0.728in x 0.591in\] |

**Comment ça marche ?**

![image99](media/bbc52b600c70618e83a69bfee9fdbe16.png)Le buzzer actif, également connu sous le nom de buzzer indicateur, utilise une alimentation CC et produira une fréquence dès qu'il est alimenté grâce à son circuit imprimé intégré. Cependant, il n'a qu'une seule fréquence et peut être pulsé. Il génère un son d'environ 2,5 kHz lorsque le signal est haut.

Brochage

![image100](media/ef8376d23e540d86886923ec5c5425c2.png)

SIN est la broche du buzzer actif que nous connectons à l'Arduino.

NC signifie non connecté à quoi que ce soit.

GND doit être connecté à la masse de l'Arduino.

**Schéma de connexion**

Connectez le signal (S) à la broche 8 de l'Arduino et la masse (-) à GND. La broche du milieu n'est pas utilisée.

| **KY-012** | **Arduino** |
|------------|-------------|
| S milieu | Pin 8 |
| – | GND |
