### Proyecto 5: Módulo de Zumbador Activo
![image97](media/ea727c6d18d08e6ac756f76b11698724.png)

**Descripción**

![image98](media/238b0ea29901d6cf1e09b99f5297b5d3.png) El zumbador activo es el módulo más simple para producir sonido. Puede controlarlo con un nivel alto/bajo.

Este módulo se utiliza ampliamente en nuestros electrodomésticos diarios como PC, refrigeradores, teléfonos, etc.

Además, puede crear muchos proyectos interactivos interesantes con este pequeño pero útil módulo. ¡Solo pruébelo! Encontrará el sonido electrónico que crea tan fascinante.

**Especificación**

| Voltaje de funcionamiento | 3.5V ~ 5.5V |
|---------------------------|-------------------------------------|
| Corriente máxima | 30mA / 5VDC |
| Frecuencia de resonancia | 2500Hz ± 300Hz |
| Salida de sonido mínima | 85Db @ 10cm |
| Temperatura de trabajo | -20°C ~ 70°C \[-4°F ~ 158°F\] |
| Temperatura de almacenamiento | -30°C ~ 105°C \[-22°F ~ 221°F\] |
| Dimensiones de la placa | 18.5mm x 15mm \[0.728in x 0.591in\] |

**¿Cómo funciona?**

![image99](media/bbc52b600c70618e83a69bfee9fdbe16.png)El zumbador activo, también conocido como zumbador indicador, utiliza alimentación de CC y producirá una frecuencia inmediatamente cuando se le suministre energía, gracias a su PCB incorporado. Sin embargo, solo tiene una frecuencia y puede ser pulsado. Genera un sonido de aproximadamente 2.5kHz cuando la señal es alta.

Pinout

![image100](media/ef8376d23e540d86886923ec5c5425c2.png)

SIN es el pin del zumbador activo que conectamos al Arduino.

NC significa no conectar a nada.

GND debe conectarse a la tierra del Arduino.

**Diagrama de conexión**

Conecte la señal (S) al pin 8 del Arduino y Tierra (-) a GND. El pin central no se utiliza.

| **KY-012** | **Arduino** |
|------------|-------------|
| S central | Pin 8 |
| – | GND |
