### プロジェクト 35: HC-SR04 超音波センサー
![image397](media/99cd3769283989d51dccb1ebf97e48fc.jpeg)

**説明**

![image398](media/e2718675213988aadff257507dfdcfe9.png) HC-SR04 超音波距離センサーを使って、次の Arduino プロジェクトにコウモリの能力を与えましょう。このセンサーは、最大 13 フィート離れた物体の距離を報告できます。これは、ロボットが壁にぶつかるのを避けようとしている場合に非常に役立つ情報です！これらは低消費電力（バッテリー駆動デバイスに適しています）、安価で、インターフェースが簡単で、愛好家の間で非常に人気があります。そして、おまけに、最新のロボット発明のためのウォーリーロボットの目のようにクールに見えます！

**超音波とは？**

超音波とは、人間の可聴範囲を超える周波数を持つ高周波の音波です。

![image399](media/ba104f24fe2132c37c84169a8b328411.png)

人間の耳は、1秒間に約20回（低いうなり声）から約20,000回（高音の口笛）の範囲で振動する音波を聞くことができます。しかし、超音波は20,000 Hzを超える周波数を持つため、人間には聞こえません。

ハードウェア概要

HC-SR04 超音波距離センサーの核となるのは、2つの超音波トランスデューサーです。1つは送信機として機能し、電気信号を40 KHzの超音波パルスに変換します。受信機は送信されたパルスをリッスンします。受信すると、パルスが移動した距離を決定するために使用できる幅の出力パルスを生成します。非常に簡単です！

このセンサーは小型で、あらゆるロボットプロジェクトで使いやすく、2 cmから400 cm（約1インチから13フィート）の非接触距離検出を3 mmの精度で提供します。5ボルトで動作するため、Arduinoまたはその他の5Vロジックマイクロコントローラーに直接接続できます。

**仕様**

| 動作電圧             | DC 5V          |
|----------------------|----------------|
| 動作電流             | 15mA           |
| 動作周波数           | 40KHz          |
| 最大範囲             | 4m             |
| 最小範囲             | 2cm            |
| 測距精度             | 3mm            |
| 測定角度             | 15度           |
| トリガー入力信号     | 10µS TTLパルス |
| 寸法                 | 45 x 20 x 15mm |

**動作原理**

すべては、Trigger ピンに少なくとも 10 µS (10 マイクロ秒) の持続時間のパルスが印加されることから始まります。それに応答して、センサーは 40 KHz で 8 つのパルスの音波バーストを送信します。この 8 パルスパターンは、デバイスからの「超音波シグネチャ」をユニークにし、受信機が送信されたパターンを周囲の超音波ノイズと区別できるようにします。

8 つの超音波パルスは、送信機から離れて空気中を伝播します。その間、Echo ピンは HIGH になり、エコーバック信号の開始を形成し始めます。

もしこれらのパルスが反射されなかった場合、Echo 信号は 38 mS (38 ミリ秒) 後にタイムアウトし、LOW に戻ります。したがって、38 mS のパルスは、センサーの範囲内に障害物がないことを示します。

![image400](media/90d822fac4a058c28775e90ce42c7341.GIF)

これらのパルスが反射された場合、信号が受信されるとすぐに Echo ピンは LOW になります。これにより、信号が受信されるまでにかかった時間に応じて、幅が 150 µS から 25 mS の間で変化するパルスが生成されます。

![image401](media/93f97e0e8bb5b3b35841f8e2b55cf5be.GIF)

受信したパルスの幅は、反射された物体までの距離を計算するために使用されます。これは、高校で習った単純な距離-速度-時間の方程式を使って計算できます。もし忘れてしまった場合でも、距離、速度、時間の方程式を覚える簡単な方法は、文字を三角形に入れることです。

![image402](media/6fe1c19b0ed28bcec26818ce14dceab5.png)

より明確にするために例を挙げましょう。センサーの前に未知の距離にある物体があり、Echo ピンで幅 500 µS のパルスを受信したとします。それでは、物体がセンサーからどれくらい離れているかを計算してみましょう。以下の式を使用します。

距離 = 速度 × 時間

ここで、時間の値は 500 µs であり、速度はわかっています。どのような速度でしょうか？もちろん音速です！それは 340 m/s です。距離を計算するために、音速を cm/µs に変換する必要があります。「音速をセンチメートル毎マイクロ秒で」とGoogleで検索すると、0.034 cm/µs であると表示されます。計算することもできますが、検索する方が簡単です。いずれにしても、この情報があれば距離を計算できます！

距離 = 0.034 cm/µs × 500 µs

しかし、これで終わりではありません！パルスは信号が送信されて反射されるまでにかかった時間を示すことを覚えておいてください。したがって、距離を得るには、結果を半分にする必要があります。

距離 = (0.034 cm/µs × 500 µs) / 2

距離 = 8.5 cm

したがって、物体はセンサーから **8.5 センチメートル**離れていることがわかりました。

ピン配置

![image403](media/2c139d919213a2a586358c22c2f7d1b2.png)

VCC は HC-SR04 超音波距離センサーの電源であり、Arduino の 5V ピンに接続します。

Trig ピンは超音波パルスをトリガーするために使用されます。

Echo ピンは、反射された信号が受信されたときにパルスを生成します。パルスの長さは、送信された信号が検出されるまでにかかった時間に比例します。

GND は Arduino のグランドに接続する必要があります。
