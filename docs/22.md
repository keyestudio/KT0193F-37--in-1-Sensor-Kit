### プロジェクト22：メタルタッチセンサー
![image274](media/2f4333a35da384beefbe5e3bfdd060d6.png)

**説明**

KY-036メタルタッチセンサーモジュールは、ダーリントンおよびPNトランジスタを搭載しています。その信号は、2つのコンパレータで構成されるLM393コンパレータICによって制御されます。トランジスタのベースで表されるトランジスタ上のバーワイヤーに触れると、センサーが作動します。

**仕様**

| 供給電圧 | 3.3V〜5V           |
|----------------|--------------------|
| インターフェース | アナログおよびデジタル |
| サイズ         | 34 x 16 mm         |
| 重量           | 4g                 |

**動作原理**

基本的に、KY-036メタルタッチセンサーモジュールの機能は3つの主要コンポーネントに分かれています。まず、モジュールの前面にあるセンサーユニットが物理的に領域を測定し、アナログ信号を第2のユニットであるアンプに送信します。

アンプは信号を増幅し、ポテンショメータの抵抗値に応じて信号をモジュールの analog output に送信します。また、ポテンショメータのノブを調整することでセンサーの感度を設定できます。時計回りに回すと感度が上がり、反時計回りに回すと感度が下がります。これは図に示されています。![image275](media/921f112fadc20b4e800952a449f63dd2.jpeg)

コンパレータは、信号が特定の値を下回るとデジタル出力を切り替え、LEDを点灯させます。

ピン配置

![image276](media/96bbe0a4aa3761811f401c2b3937dc6a.png)

DOUT は、Arduino に接続するメタルタッチセンサーのデジタルピンです。

AOUT は、Arduino に接続するメタルタッチセンサーのアナログピンです。

VCC は Arduino の +5V 電源に接続する必要があります。

GND は Arduino のグランドに接続する必要があります。

**接続図**

ボードの analog output (A0) を Arduino の Pin A0 に、デジタル出力 (D0) を Pin 3 に接続します。電源ライン (+) とグランド (G) をそれぞれ 5V と GND に接続します。
