### Proyecto 26: Sensor de sonido analógico
![image310](media/424183e8acc300032bed2a063fb90681.png)

**Descripción**

Este módulo está compuesto por tres elementos funcionales: el sensor en la parte frontal del módulo que realiza la medición, luego la señal analógica se envía al amplificador.

Este amplifica la señal según la ganancia determinada por el potenciómetro y envía la señal a la salida analógica del módulo.

La tercera parte consiste en un comparador que conmuta la salida digital y el diodo cuando la señal cae por debajo de un cierto valor.

Descripción general del hardware

El sensor de sonido es una pequeña placa que combina un micrófono (50Hz-10kHz) y algunos circuitos de procesamiento para convertir las ondas sonoras en señales eléctricas.

Esta señal eléctrica se alimenta al comparador de alta precisión LM393 integrado para digitalizarla y está disponible en el pin OUT.

![image311](media/4b5999c21dd83b06ca816d27415fa8de.jpeg)

El módulo tiene un potenciómetro incorporado para el ajuste de sensibilidad de la señal OUT.

Puede establecer un umbral usando un potenciómetro; de modo que cuando la amplitud del sonido exceda el valor del umbral, el módulo emitirá LOW, de lo contrario HIGH.

Esta configuración es muy útil cuando desea activar una acción cuando se alcanza un cierto umbral. Por ejemplo, cuando la amplitud del sonido cruza un umbral (cuando se detecta un golpe), puede activar un relé para controlar la luz. ¡Ya lo tienes!

Consejo: Gire la perilla en sentido antihorario para aumentar la sensibilidad y en sentido horario para disminuirla.

![image312](media/824c444c506bcd9a06fd2e946d297eb5.jpeg)

Además de esto, el módulo tiene dos LED. El LED de encendido se iluminará cuando el módulo esté alimentado. El LED de estado se iluminará cuando la salida digital pase a LOW.

Pinout

![image313](media/3049a43b76cce18b8c2d6c8b579d6210.png)DOUT es el pin digital del sensor de sonido que conectamos al Arduino.

AOUT es el pin analógico del sensor de sonido que conectamos al Arduino.

VCC debe conectarse a la alimentación de +5V del Arduino.

GND debe conectarse a la tierra del Arduino.
