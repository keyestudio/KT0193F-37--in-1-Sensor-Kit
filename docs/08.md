### プロジェクト8：5V 1チャンネルリレーモジュール
![image124](media/176c9edc3ff35f4b99e4c62b7e0f6946.png)

**説明**

![image125](media/fb4656edaa1d221d06121f420e200225.png) このシングルリレーモジュールは、インタラクティブなプロジェクトで使用できます。このモジュールはSONGLE 5Vの高品質リレーを使用しています。照明、電気、その他の機器の制御にも使用できます。

モジュラー設計により、Arduinoボードとの併用が容易です。ソレノイドバルブ、ランプ、モーター、その他の大電流または高電圧デバイスなど、デジタルIOポートを介して制御できます。

**仕様**

| TTL制御信号 | 5VDCから12VDC（一部のボードは3.3Vで動作する場合があります） |
|-------------|-------------------------------------------------------------|
| 最大AC      | 10A 250VAC                                                  |
| 最大DC      | 10A 30VDC                                                   |
| 接点タイプ  | NCおよびNO                                                  |
| ボード寸法  | 27mm x 34mm \[1.063in x 1.338in\]                           |

**仕組み**

リレーは、比較的小さな電流で動作し、はるかに大きな電流を制御できる**電磁スイッチ**です。

リレーが1つの回路を使用して別の回路をオンにする方法を示す簡単なアニメーションです。

![image126](media/4f07201fefa4363dc33693ef045bdbff.GIF)

最初に、最初の回路はオフになっており、何らかの要因（センサーまたはスイッチの閉鎖）がそれをオンにするまで電流は流れません。2番目の回路もオフになっています。

小さな電流が最初の回路を流れると、電磁石が作動し、その周囲に磁場を生成します。

励磁された電磁石は、2番目の回路の接点を引き寄せ、スイッチを閉じ、はるかに大きな電流が2番目の回路を流れることを可能にします。

電流が流れなくなると、接点は元の位置に戻り、2番目の回路を再びオフにします。

リレーの基本

通常、リレーには5つのピンがあり、そのうち3つは制御したいデバイスに接続する高電圧端子（NC、COM、およびNO）です。

![image127](media/858de74b9f862df1c0bc93022bc3a7bb.png)

主電源は共通（COM）端子でリレーに入ります。NCおよびNO端子の使用は、デバイスをオンにするかオフにするかによって異なります。

残りの2つのピン（coil1とcoil2）の間には、電磁石のように機能するコイルがあります。

![image128](media/f52b412166d95ed2b5916f1b553504c3.GIF)

コイルに電流が流れると、電磁石が帯電し、スイッチの内部接点を動かします。そのとき、常開（NO）端子は共通（COM）に接続され、常閉（NC）端子は切断されます。

コイルに電流が流れなくなると、内部接点は初期状態に戻ります。つまり、常閉（NC）端子は共通（COM）に接続され、常開（NO）端子は再び開きます。

これは単極双投スイッチ（**SPDT**）として知られています。

ピン配置

![image129](media/daed0e89dd4f1c8fe76ba65a037cb840.png)

SINは、Arduinoに接続するリレー信号ピンです。

VCCはArduinoの+5V電源に接続する必要があります。

GNDはArduinoのグランドに接続する必要があります。

**接続図**

回路のDC部分については、S（信号）をArduinoのPin 10に接続し、電源ライン（+）とグランド（-）をそれぞれ+5とGNDに接続します。

AC側では、供給をCommon（中央接点）に接続し、必要に応じてNCまたはNOを使用します。

NO（常開）は（S）がHIGHのときに電力を受け取ります。NC（常閉）は（S）がHIGHのときに切断されます。

ACを扱う実験では常に細心の注意を払ってください。感電は重傷につながる可能性があります。

**実行結果の例**

このリレーモジュールはHIGHレベルでアクティブになります。

適切に配線し、電源を投入し、上記のコードをボードにアップロードすると、リレーが2秒間オン（ON接続、NC切断）になり、その後2秒間オフ（NC閉鎖、ON切断）になるのが繰り返し循環的に表示されます。

リレーがオンになると、外部LEDが点灯します。リレーがオフになると、外部LEDは消灯します。
