### Proyecto 16: Sensor de evitación de obstáculos por infrarrojos
![image216](media/05cc327b80e26f65c3b2fd45c03a572d.png)

**Descripción**

El módulo KY-032 Obstacle Avoidance Sensor es un sensor de proximidad por infrarrojos con distancia ajustable, diseñado para robots con ruedas.

La distancia de detección del sensor va de 2cm a 40cm, y se puede ajustar girando la perilla del potenciómetro. El voltaje de funcionamiento es de 3.3V-5V, por lo que es adecuado para una variedad de microcontroladores como Arduino, ESP32, Teensy, ESP8266, Raspberry Pi y otros.

Tiene una fuerte adaptabilidad a la luz ambiental y es bastante preciso para detectar cambios en el entorno.

**Especificaciones**

| Voltaje de funcionamiento     | 3.3V – 5V DC                                                    |
|---------------------|-----------------------------------------------------------------|
| Corriente de funcionamiento     | ≥ 20mA                                                          |
| Temperatura de funcionamiento | -10°C – 50°C \[14°F – 122°F\]                                   |
| Distancia de detección  | 2cm – 40cm \[0.79in – 15.75in\]                                 |
| Interfaz IO        | Interfaz de 4 hilos (-/+/S/EN)                                     |
| Señal de salida       | Nivel TTL (nivel bajo si se detecta un obstáculo, alto si no hay obstáculo) |
| Método de ajuste   | ajuste por resistencia de múltiples vueltas                                |
| Frecuencia del pulso IR  | 38kHz según la hoja de datos del HS0038DB                           |
| Ángulo efectivo     | 35°                                                             |
| Tamaño de la placa          | 1.6cm x 4cm \[0.62in x 1.57in\]                                 |
| Peso              | 9g                                                              |

**¿Cómo funciona?**

El módulo produce una onda cuadrada de 38KHz generada principalmente por el 555 Timer IC y VR1.

Este pulso de 38KHz se usa para encender/apagar el LED IR. Si hay un objeto frente al LED IR, los pulsos infrarrojos se reflejan y parte de ese IR reflejado es detectado por el receptor IR (HS0038BD).

Esto indicará al módulo que hay un obstáculo y hará que el pin de señal S pase a LOW. Si no hay obstáculo, el pin S estará en HIGH. VR2 se utiliza para ajustar la distancia a la que se detecta el obstáculo. El módulo tiene un rango de detección de 2~40cm.

![image217](media/0809395a1fd9593d99e7396a7f735005.jpeg)

Se proporciona el pin EN y el puente EN para controlar la detección del módulo. Coloca un jumper en EN para que el módulo esté siempre habilitado.

Si quieres controlar la activación/desactivación del módulo, quita el jumper y conecta el pin EN a HIGH para habilitarlo o a LOW para deshabilitarlo.

Asignación de pines

![image218](media/a743585d7af39838b9b4cce4ef8c52ab.png)

SIN es el pin de señal del sensor de evitación de obstáculos que conectamos al Arduino.

VCC debe conectarse a la alimentación +5V del Arduino.

GND debe conectarse a la masa del Arduino.

EN habilita el sensor de evitación de obstáculos.

**Diagrama de conexión**

Conecta la línea GND del módulo (el pin más a la izquierda) a GND en el Arduino y el + (el segundo pin) a 5V. Conecta la señal (out) al pin 3 del Arduino.
