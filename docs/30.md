### Project 30: DHT11 Sensor
![image342](media/2c757968d61641b1684e3aab51d470fb.png)

**Description**

![image343](media/a0150fc27cec190a2ad34b1e1ec0159f.png) Empower your next Arduino project with the ability to sense its surroundings using the inexpensive DHT11 digital temperature & humidity sensor module from AOSONG.

This sensor is pre-calibrated and requires no additional components, allowing you to start measuring relative humidity and temperature immediately.

**Specification**

| Humidity measurement range         | 20% to 90% RH                 |

| Temperature measurement range      | 0ºC to 50ºC \[32ºF to 122ºF\] |
| Temperature measurement accuracy   | ±2ºC                          |
| Temperature measurement resolution | 1ºC                           |
| Signal transmission range          | 20m                           |

**How Does It Work?**

Inside the DHT11, there is a humidity sensing component along with a Thermistor.

![image344](media/f80d1ed3279b692217b2dbbdafd27cf2.jpeg) The humidity sensing component has two electrodes with a moisture-holding substrate sandwiched between them.

The ions are released by the substrate as water vapor is absorbed by it, which in turn increases the conductivity between the electrodes.

The change in resistance between the two electrodes is proportional to the relative humidity. Higher relative humidity decreases the resistance between the electrodes, while lower relative humidity increases the resistance between the electrodes.

![image345](media/0c0c862cb60b82a8bdce8ff7e4a71d76.png)

DHt11 also contains an NTC/Thermistor to measure temperature. A thermistor is a thermal resistor whose resistance changes drastically with temperature. The term “NTC” means “Negative Temperature Coefficient”, which means that the resistance decreases with an increase in temperature.

![image346](media/889784fe955d1f0bb4c51c6862f41cf4.png)

On the other side, there is a small PCB with an 8-bit SOIC-14 packaged IC. This IC measures and processes the analog signal with stored calibration coefficients, performs analog-to-digital conversion, and outputs a digital signal with the temperature and humidity.

![image347](media/dfce90dc9ee230c2ca1d3b8f436102dd.jpeg)

Installing DHT library

DHT11 sensors have their own single-wire protocol for transferring data. This protocol requires precise timing. Fortunately, **DHT Library** was written to hide all the complexities so that we can issue simple commands to read the temperature and humidity data.

Download the library first by visiting the [GitHub repo](https://github.com/RobTillaart/Arduino/tree/master/libraries/DHTlib), then download the zip:

<https://github.com/RobTillaart/Arduino/tree/master/libraries/DHTlib>

To install it, open the Arduino IDE, go to Sketch > Include Library > Add .ZIP Library, and then select the DHTlib ZIP file that you just downloaded.
