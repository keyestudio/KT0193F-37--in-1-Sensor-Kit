### プロジェクト30：DHT11センサー
![image342](media/2c757968d61641b1684e3aab51d470fb.png)

**説明**

![image343](media/a0150fc27cec190a2ad34b1e1ec0159f.png) AOSONG製の安価なDHT11デジタル温度・湿度センサーモジュールを使用して、次のArduinoプロジェクトに周囲を感知する機能を与えましょう。

このセンサーは事前に校正されており、追加のコンポーネントを必要としないため、すぐに相対湿度と温度の測定を開始できます。

**仕様**

| 動作電圧                   | 3.3V～5.5V                    |
|----------------------------|-------------------------------|
| 湿度測定範囲               | 20%～90% RH                   |
| 湿度測定精度               | ±5% RH                        |
| 湿度測定分解能             | 1% RH                         |
| 温度測定範囲               | 0ºC～50ºC \[32ºF～122ºF\] |
| 温度測定精度               | ±2ºC                          |
| 温度測定分解能             | 1ºC                           |
| 信号伝送範囲               | 20m                           |

**仕組み**

DHT11の内部には、サーミスタとともに湿度感知コンポーネントがあります。

![image344](media/f80d1ed3279b692217b2dbbdafd27cf2.jpeg) 湿度感知コンポーネントは、水分保持基板が挟まれた2つの電極で構成されています。

水蒸気が基板に吸収されると、基板からイオンが放出され、これにより電極間の導電率が増加します。

2つの電極間の抵抗の変化は相対湿度に比例します。相対湿度が高いほど電極間の抵抗は減少し、相対湿度が低いほど電極間の抵抗は増加します。

![image345](media/0c0c862cb60b82a8bdce8ff7e4a71d76.png)

DHT11には、温度を測定するためのNTC/サーミスタも含まれています。サーミスタは、温度によって抵抗が劇的に変化する感熱抵抗器です。「NTC」という用語は「負の温度係数」を意味し、温度の上昇とともに抵抗が減少することを意味します。

![image346](media/889784fe955d1f0bb4c51c6862f41cf4.png)

反対側には、8ビットのSOIC-14パッケージICを備えた小さなPCBがあります。このICは、保存された校正係数でアナログ信号を測定および処理し、アナログ-デジタル変換を行い、温度と湿度を含むデジタル信号を出力します。

![image347](media/dfce90dc9ee230c2ca1d3b8f436102dd.jpeg)

ピン配置

![image348](media/048bee6825ca1cd75d6a69122facde85.png)

- (VCC) ピンはセンサーに電力を供給します。

SINピンはセンサーとArduino間の通信に使用されます。

– (GND) はArduinoのグランドに接続する必要があります。

**接続図**

電源ライン（中央）とグランド（-）をそれぞれ+5とGNDに接続します。信号（S）をArduinoのPin 8に接続します。

| **KY-015** | **Arduino** |
|------------|-------------|
| S          | Pin 8       |
| 中央       | +5V         |
| –          | GND         |

DHTライブラリのインストール

DHT11センサーは、データ転送のために独自の単線プロトコルを持っています。このプロトコルは正確なタイミングを必要とします。幸いなことに、**DHT Library**はすべての複雑さを隠すために書かれており、温度と湿度のデータを読み取るための簡単なコマンドを発行できます。

まず、[GitHub repo](https://github.com/RobTillaart/Arduino/tree/master/libraries/DHTlib)にアクセスしてライブラリをダウンロードし、zipファイルをダウンロードします。

<https://github.com/RobTillaart/Arduino/tree/master/libraries/DHTlib>

インストールするには、Arduino IDEを開き、Sketch > Include Library > Add .ZIP Libraryに移動し、ダウンロードしたDHTlib ZIPファイルを選択します。
