### プロジェクト1：2色LEDモジュール
![image57](media/b3f1461038d87065bcc02b43f548a87f.png)

**概要**

![image58](media/dd4315f7b29bba13a88e802812db9ce1.png)

2色LEDモジュールは赤色と黄色の光を発することができます。blinkのコードで点灯させることができ、PWMを使用して各色の強度を調整することもできます。

Arduino、Raspberry Pi、ESP32などの人気のある電子プラットフォームと互換性があります。

このモジュールは、共通カソード5mm赤/黄LED、0Ω抵抗、および3つのオスヘッダーピンで構成されています。動作電圧は2.0Vから2.5Vの間であるため、Arduinoに接続する際には焼損を防ぐために制限抵抗を使用する必要があります。

**仕様**

| 動作電圧                   | 2V〜2.5V      |
|----------------------------|---------------|
| 動作電流                   | 10mA          |
| 直径                       | 5mm           |
| パッケージタイプ           | 拡散          |
| 色                         | 赤 + 黄       |
| ビーム角度                 | 150           |
| 波長                       | 571nm + 644nm |
| 輝度強度 (MCD)             | 20-40; 40-80  |

**仕組み**

![image59](media/6dd11985300f9c6740f17024dfdef4fe.jpeg)

2色発光ダイオード（LED）は、通常、1色だけでなく、赤と黄色の2つの異なる色の光を発することができます。

3mmまたは5mmのエポキシパッケージに収められています。3つのリードがあり、共通カソードまたは共通アノードが利用可能です。2色LEDは、回路内で逆並列に配置され、カソード/アノードによって接続された2つのLED端子、またはピンを備えています。

正の電圧をLED端子の1つに向けることで、その端子が対応する色の光を発します。電圧の方向が逆になると、もう一方の色の光が発せられます。

2色LEDでは、一度に1つのピンしか電圧を受け取ることができません。その結果、このタイプのLEDは、テレビ、デジタルカメラ、リモコンなど、さまざまなデバイスのインジケーターライトとして頻繁に機能します。

ピン配置

![image60](media/fdc7c3b09e1c67f1337a2a5c2d1f7989.png)

YELLOWは、Arduinoに接続する黄色のLEDピンです。

REDは、Arduinoに接続する赤色のLEDピンです。

GNDはArduinoのGNDに接続する必要があります。

**接続図**

ボード上のYELLOWピン（Y）をArduinoのPin 10に接続し、REDピン（R）をPin 11に接続します。最後に、GNDピン（G）をGNDに接続します。
