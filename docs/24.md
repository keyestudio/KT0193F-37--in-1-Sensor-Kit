### プロジェクト24：デジタル温度センサー
![image293](media/de6ed50629655fdce32d490724be81b0.png)

**説明**

![image294](media/b338379ac763a544af4745268ad27ccb.png) KY-028デジタル温度センサーは、サーミスタの抵抗に基づいて温度変化を測定します。このモジュールにはデジタル出力とアナログ出力の両方があり、デジタルインターフェースには検出閾値を調整するためのポテンショメータがあります。Arduino、Raspberry Pi、ESP32、およびその他のマイクロコントローラと互換性があります。

このモジュールは、サーミスタの動作原理（環境の温度変化に応じて抵抗が変化する）に基づいています。

周囲の温度変化を感知し、そのデータをArduinoボードのアナログIOに送信できます。

必要なのは、簡単なプログラミングによってセンサーの出力データを摂氏温度に変換し、最終的にモニターに表示することだけです。

これは便利で効果的であるため、ガーデニング、家庭用警報システム、その他のデバイスに広く応用されています。

**仕様**

動作電圧 3.3V ~ 5.5V

温度測定範囲 -55°C ～ 125°C [-67°F ～ 257°F]

測定精度 ±0.5°C

ボード寸法 15mm x 36mm [0.6in x 1.4in]

**どのように機能しますか？**

サーミスタ、または単に**熱**感応**抵抗**器は、温度に応じて抵抗が変化する原理で動作する**温度センサー**です。これらは半導体材料で作られています。サーミスタの回路記号は図に示されています。

![Thermistor: Construction, Working Principle, Types and Applications 1](media/7b397ebe02877827bacfad37fc985a63.png)

サーミスタは、温度変化による抵抗変化という単純な原理で動作します。周囲温度が変化すると、サーミスタは自身の素子を自己発熱させ始めます。その抵抗値は、この温度変化に応じて変化します。この変化は、使用されるサーミスタの種類によって異なります。異なる種類のサーミスタの抵抗温度特性は、次のセクションで説明されています。

**NTCサーミスタ**

NTCは負の温度係数を意味します。これらは、高い負の温度係数を持つセラミック半導体です。NTCの抵抗は、温度の上昇とともに非線形に減少します。

NTCおよびPTCサーミスタの回路記号は、次の図に示されています。

![Thermistor: Construction, Working Principle, Types and Applications 3](media/b07d58f8c5e6b99b2f76cab5fad78e1b.png)

**PTCサーミスタ**

PTCサーミスタは正の温度係数抵抗器であり、多結晶セラミック材料で作られています。PTCの抵抗は、温度の上昇とともに非線形に増加します。PTCサーミスタは、スイッチングポイント（TR）に達するまで、温度による抵抗のわずかな変化しか示しません。

NTCとPTCの温度抵抗特性は、次の図に示されています。

ピン配置

![image295](media/29199bde6bd122dffdfd8da92d39a29d.png)

DOUTは、Arduinoに接続するデジタル温度センサーのデジタルピンです。

AOUTは、Arduinoに接続するデジタル温度センサーのアナログピンです。

VCCはArduinoの+5V電源に接続する必要があります。

GNDはArduinoのグランドに接続する必要があります。

**接続図**

ボードのアナログ出力（A0）をArduinoのピンA0に、デジタル出力（D0）をピン3に接続します。電源ライン（+）とグランド（G）をそれぞれ5VとGNDに接続します。
