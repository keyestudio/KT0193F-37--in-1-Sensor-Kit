### プロジェクト3：DIP RGB LEDモジュール
![image77](media/65b4e00d0676e2d0fc93efa7cc53637d.png)

**説明**

![image78](media/ed7923ded5006c6413a9b04cc91ed31f.png)KY-016フルカラーRGB LEDは、赤、緑、青の光を混合することで、さまざまな色を発光します。Arduino、Raspberry Pi、ESP32などの多くの一般的なマイクロコントローラーと互換性があります。

**仕様**

このモジュールは、5mm RGB LED、焼損を防ぐための3つの150Ω制限抵抗、および4つのオスヘッダーピンで構成されています。各カラーピンのPWM信号を調整すると、異なる色が得られます。

| 動作電圧          | 3.3-5V                          |
|-------------------|---------------------------------|
| 動作電流          | 10mA                            |
| 色                | 赤 + 緑 + 青                    |
| LED駆動モード     | 共通カソード駆動                |
| LED直径           | 5mm                             |
| ボードサイズ      | 15mm x 19mm \[0.59in x 0.75in\] |

**どのように機能しますか？**

RGB LEDは、1つのパッケージに3つのLEDを組み合わせたものです。

- 1x **R**ed LED
- 1x **G**reen LED
- 1x **B**lue LED

これら3つの色を組み合わせることで、ほとんどすべての色を生成できます。RGB LEDを次の図に示します。

![image79](media/46dd8d469848520fa5479593a47c2c80.png)

**異なる色を作成する方法は？**

RGB LEDを使用すると、もちろん赤、緑、青の光を生成でき、各LEDの強度を設定することで、他の色も生成できます。

たとえば、純粋な青い光を生成するには、青いLEDを最高の強度に設定し、緑と赤のLEDを最低の強度に設定します。白い光の場合は、3つのLEDすべてを最高の強度に設定します。

**色の混合**

他の色を生成するには、3つの色を異なる強度で組み合わせることができます。各LEDの強度を調整するには、PWM信号を使用できます。

LEDは互いに非常に近いため、私たちの目は3つの色を個別にではなく、色の組み合わせの結果を認識します。

色の組み合わせ方を知るには、次の図をご覧ください。これは最も単純な色混合図ですが、どのように機能し、どのように異なる色を生成するかを理解するのに役立ちます。

![IMG_258](media/cd5a04fd23a99ea63dfeca17b82a5cc6.png)

**共通アノードおよび共通カソードRGB LED**

RGB LEDには、*共通アノード*LEDと*共通カソード*LEDの2種類があります。次の図は、共通アノードLEDと共通カソードLEDを示しています。

![IMG_259](media/d22c98c442111ecc653c0e97280458ed.png)

共通カソードRGB LEDでは、3つのLEDすべてが負の接続（カソード）を共有します。共通アノードRGB LEDでは、3つのLEDが正の接続（アノード）を共有します。これにより、各LEDに1つずつ、共通カソードまたは共通アノードの4つのピンを持つLEDができます。

**ピン配置**

![image80](media/a861e76009057d6461142b869505a3ea.png)

GREENは、Arduinoに接続する緑色LEDピンです。

REDは、Arduinoに接続する赤色LEDピンです。

BLUEは、Arduinoに接続する青色LEDピンです。

GNDはArduinoのグランドに接続する必要があります。

**接続図**

モジュールの赤ピン（R）をArduinoのPin 11に接続します。青（B）をPin 10に、緑（G）をPin 9に、グランド（-）をGNDに接続します。
