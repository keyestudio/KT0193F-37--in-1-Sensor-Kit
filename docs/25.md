### プロジェクト25：高感度サウンドセンサー
![image300](media/6ac46cab3c98cd643a045a6c37a9bcde.png)

**説明**

![image301](media/9411fddd97afe35a5881451827c04ed3.png) 高感度サウンドセンサーは、通常、周囲の音の音量を検出するために使用されます。このセンサーにはポテンショメータが付属しており、信号ゲインを調整するために回すことができます。

音声操作スイッチのような、面白くてインタラクティブな作品を作るために使用できます。

**仕様**

| 動作電圧                   | 2v ~ 2.5v     |
|----------------------------|---------------|
| 動作電流                   | 10mA          |
| 直径                       | 5mm           |
| パッケージタイプ           | 拡散          |
| 色                         | 赤 + 黄       |
| ビーム角度                 | 150           |
| 波長                       | 571nm + 644nm |
| 輝度強度 (MCD)             | 20-40; 40-80  |

**仕組み**

マイクの内部には薄い振動板があり、これは実際にはコンデンサの1つのプレートです。2番目のプレートはバックプレートで、振動板に近く平行に配置されています。

![image302](media/d8c335ee61d0c8f025840792bdf6f685.GIF)

マイクに向かって話すと、あなたの声によって生成された音波が振動板に当たり、振動させます。

音が原因で振動板が振動すると、プレートが近づいたり離れたりするにつれて静電容量が変化します。

静電容量が変化すると、プレート間の電圧が変化し、これを測定することで音の振幅を決定できます。

ハードウェア概要

サウンドセンサーは、マイク（50Hz-10kHz）と、音波を電気信号に変換するための処理回路を組み合わせた小さなボードです。

この電気信号は、オンボードのLM393高精度コンパレータに供給され、デジタル化されてOUTピンで利用可能になります。

![image303](media/4b5999c21dd83b06ca816d27415fa8de.jpeg)

このモジュールには、OUT信号の感度調整用のポテンショメータが内蔵されています。

ポテンショメータを使用してしきい値を設定できます。これにより、音の振幅がしきい値を超えるとモジュールはLOWを出力し、それ以外の場合はHIGHを出力します。

この設定は、特定のしきい値に達したときにアクションをトリガーしたい場合に非常に役立ちます。たとえば、音の振幅がしきい値を超えたとき（ノックが検出されたとき）に、リレーをアクティブにしてライトを制御できます。お分かりいただけたでしょうか！

ヒント：ノブを反時計回りに回すと感度が上がり、時計回りに回すと感度が下がります。

![image304](media/824c444c506bcd9a06fd2e946d297eb5.jpeg)

これに加えて、モジュールには2つのLEDがあります。モジュールに電源が供給されると、電源LEDが点灯します。デジタル出力がLOWになると、ステータスLEDが点灯します。

ピン配置

![image305](media/fc97ac10b0cf18b1ca0cd0d416a123c1.png)

DOUTは、Arduinoに接続するサウンドセンサーのデジタルピンです。

AOUTは、Arduinoに接続するサウンドセンサーのアナログピンです。

VCCはArduinoの+5V電源に接続する必要があります。

GNDはArduinoのGNDに接続する必要があります。

**接続図**

ボードのアナログ出力（A0）をArduinoのピンA0に、デジタル出力（D0）をピン3に接続します。電源ライン（+）とGND（G）をそれぞれ5VとGNDに接続します。
