### プロジェクト 7: レーザー送信モジュール
![image114](media/66efc386eff3e79a607b61b6805952ac.png)

**概要**

![image115](media/87f4466329e58399e7f5dedd95deca14.png) KY-008 レーザー送信モジュールはレーザーポインターとして使用できます。点状の赤いレーザービームを発します。

650nmの赤色レーザーダイオードヘッド、抵抗、3つのオスヘッダーピンで構成されています。取り扱いには注意し、レーザービームを直接目に向けないでください。

Arduino、Raspberry PI、ESP32、その他人気のあるマイクロコントローラーと互換性のあるレーザー送信モジュール。

**仕様**

| 動作電圧 | 5V                                  |
|----------|-------------------------------------|
| 出力電力 | 5mW                                 |
| 波長     | 650nm                               |
| 動作電流 | < 40mA                              |
| 動作温度 | -10°C ~ 40°C [14°F to 104°F]      |
| 基板寸法 | 18.5mm x 15mm [0.728in x 0.591in] |

**動作原理**

レーザーダイオードの動作は、主に3つのステップで行われます。

1.エネルギー吸収

レーザーダイオードは、正孔と電子が存在するp-n接合で構成されています。（ここで、正孔とは電子の欠如を意味します）。

p-n接合に特定の電圧が印加されると、電子はエネルギーを吸収し、より高いエネルギーレベルに遷移します。励起された電子の元の位置には正孔が形成されます。

電子は、正孔と再結合することなく、非常に短い時間、この励起状態にとどまります。この時間は「再結合時間」または「上位状態寿命」と呼ばれます。ほとんどのレーザーダイオードの場合、再結合時間は約1ナノ秒です。

![image116](media/bf95571c46b7b64df9b5a8bc4ae93cdf.jpeg)

2.自然放出

励起された電子の上位状態寿命の後、それらは正孔と再結合します。

電子がより高いエネルギーレベルからより低いエネルギーレベルに落ちると、エネルギーの差は光子または電磁放射に変換されます。

この同じプロセスは、LEDで光を生成するために使用されます。放出される光子のエネルギーは、2つのエネルギーレベル間の差によって与えられます。

![IMG_257](media/dc081241a01ce08e4a197e0244697080.jpeg)

3.誘導放出

レーザーダイオードからは、自然放出によって放出される光子よりも、より多くのコヒーレントな光子が必要です。

ダイオードの両側に部分反射ミラーが使用されており、自然放出によって放出された光子がp-n接合に閉じ込められ、その濃度が閾値に達するまで保持されます。

これらの閉じ込められた光子は、励起された電子が再結合時間よりも早く正孔と再結合するように刺激します。

これにより、初期光子と正確に同相の光子がさらに放出され、出力が増幅されます。光子濃度が閾値を超えると、部分反射ミラーから脱出し、明るく単色でコヒーレントな光が発生します。

ピン配置

![image118](media/12a5c5fb83439f0221beb4e72e75a420.png)

SINはArduinoに接続するレーザー信号ピンです。

NCは何も接続しないことを意味します。

GNDはArduinoのGNDに接続する必要があります。

**接続図**

モジュール信号ピン（S）をArduinoのPin 8に、GND（-）をGNDに接続します。モジュールの中央のピンは使用しません。
