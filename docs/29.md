### Proyecto 29: Módulo LCD 1602
![image336](media/22373e1a5458cd71c9d49c54a436f3fe.jpeg)

**Descripción**

![image337](media/97c4488170561a75f9dd3981cb56d65a.png) ¿Quieres que tus proyectos Arduino muestren mensajes de estado o lecturas de sensores? Entonces estas pantallas LCD podrían ser la opción perfecta. Son extremadamente comunes y una forma rápida de añadir una interfaz legible a tu proyecto.

**Especificación**

| Power Supply    | 3.3-5V                               |
|-----------------|--------------------------------------|
| Display Mode    | STN, BLUB                            |
| Display Formate | 16 Character x 2 Line                |
| Input Data      | 4-Bits or 8-Bits interface available |
| Display Font    | 5 x 8 Dots                           |
| Driving Scheme  | 1/16Duty,1/5Bias                     |
| BACKLIGHT       | blue                                 |

**¿Cómo funciona?**

Estas pantallas LCD son ideales para mostrar solo texto/caracteres, de ahí el nombre "Character LCD". La pantalla tiene una retroiluminación LED y puede mostrar 32 caracteres ASCII en dos filas con 16 caracteres en cada fila.

![image338](media/8b9b60b606d68679ce6a17e0df4ae54d.png)

Cada rectángulo contiene una cuadrícula de 5×8 píxeles

Si miras de cerca, puedes ver los pequeños rectángulos para cada carácter en la pantalla y los píxeles que forman un carácter. Cada uno de estos rectángulos es una cuadrícula de 5×8 píxeles.

Aunque solo muestran texto, vienen en muchos tamaños y colores: por ejemplo, 16×1, 16×4, 20×4, con texto blanco sobre fondo azul, con texto negro sobre verde y muchos más.

La buena noticia es que todas estas pantallas son "intercambiables": si construyes tu proyecto con una, puedes simplemente desconectarla y usar otra LCD de tamaño/color de tu elección. Es posible que tu código tenga que ajustarse al tamaño más grande, ¡pero al menos el cableado es el mismo!

Pinout

![image339](media/3a8c6d721d72a26c9d54b5c2aba51055.png)

GND debe conectarse a la tierra de Arduino.

VCC es la fuente de alimentación para la LCD que conectamos al pin de 5 voltios en el Arduino.

Vo (LCD Contrast) controla el contraste y el brillo de la LCD. Usando un simple divisor de voltaje con un potenciómetro, podemos hacer ajustes finos al contraste.

El pin RS (Register Select) permite que el Arduino le diga a la LCD si está enviando comandos o datos. Básicamente, este pin se usa para diferenciar comandos de datos.

Por ejemplo, cuando el pin RS se establece en LOW, estamos enviando comandos a la LCD (como establecer el cursor en una ubicación específica, borrar la pantalla, desplazar la pantalla a la derecha, etc.). Y cuando el pin RS se establece en HIGH, estamos enviando datos/caracteres a la LCD.

El pin R/W (Read/Write) en la LCD es para controlar si estás leyendo datos de la LCD o escribiendo datos en la LCD. Como solo estamos usando esta LCD como un dispositivo de SALIDA, vamos a conectar este pin a LOW. Esto lo fuerza al modo ESCRITURA.

El pin En (Enable) se usa para habilitar la pantalla. Es decir, cuando este pin se establece en LOW, la LCD no se preocupa por lo que sucede con R/W, RS y las líneas del bus de datos; cuando este pin se establece en HIGH, la LCD está procesando los datos entrantes.

D0-D7 (Data Bus) son los pines que transportan los datos de 8 bits que enviamos a la pantalla. Por ejemplo, si queremos ver el carácter mayúscula "A" en la pantalla, estableceremos estos pines en 0100 0001 (según la tabla ASCII) a la LCD.

Los pines A-C (Anode & Cathode) se usan para controlar la retroiluminación de la LCD.

**Diagrama de conexión**

Conectemos la pantalla LCD al Arduino. Cuatro pines de datos (D4-D7) de la LCD se conectarán a los pines digitales del Arduino de \##4-7. El pin Enable de la LCD se conectará al Arduino \##2 y el pin RS de la LCD se conectará al Arduino \##1.
