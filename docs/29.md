### プロジェクト29：1602 LCDモジュール
![image336](media/22373e1a5458cd71c9d49c54a436f3fe.jpeg)

**説明**

![image337](media/97c4488170561a75f9dd3981cb56d65a.png) Arduinoプロジェクトでステータスメッセージやセンサーの読み取り値を表示したいですか？それなら、これらのLCDディスプレイが最適かもしれません。これらは非常に一般的で、プロジェクトに読み取り可能なインターフェースを素早く追加する方法です。

**仕様**

| Power Supply    | 3.3-5V                               |
|-----------------|--------------------------------------|
| Display Mode    | STN, BLUB                            |
| Display Formate | 16 Character x 2 Line                |
| Input Data      | 4-Bits or 8-Bits interface available |
| Display Font    | 5 x 8 Dots                           |
| Driving Scheme  | 1/16Duty,1/5Bias                     |
| BACKLIGHT       | blue                                 |

**動作原理**

これらのLCDはテキスト/文字のみを表示するのに理想的であり、そのため「キャラクターLCD」という名前が付けられています。ディスプレイにはLEDバックライトがあり、2行に32個のASCII文字を、各行に16文字表示できます。

![image338](media/8b9b60b606d68679ce6a17e0df4ae54d.png)

各長方形には5×8ピクセルのグリッドが含まれています

よく見ると、ディスプレイ上の各文字の小さな長方形と、文字を構成するピクセルを実際に見ることができます。これらの長方形のそれぞれは、5×8ピクセルのグリッドです。

テキストのみを表示しますが、16×1、16×4、20×4など、多くのサイズと色があります。例えば、青い背景に白いテキスト、緑の背景に黒いテキストなど、他にもたくさんあります。

良いニュースは、これらのディスプレイはすべて「交換可能」であるということです。1つでプロジェクトを構築した場合でも、それを抜き取って、選択した別のサイズ/色のLCDを使用できます。コードはより大きなサイズに調整する必要があるかもしれませんが、少なくとも配線は同じです！

ピン配置

![image339](media/3a8c6d721d72a26c9d54b5c2aba51055.png)

GNDはArduinoのGNDに接続する必要があります。

VCCはLCDの電源であり、Arduinoの5ボルトピンに接続します。

Vo (LCD Contrast) はLCDのコントラストと明るさを制御します。ポテンショメータを備えた単純な分圧器を使用することで、コントラストを微調整できます。

RS (Register Select) ピンは、Arduinoがコマンドを送信しているのかデータを送信しているのかをLCDに伝えることができます。基本的に、このピンはコマンドとデータを区別するために使用されます。

たとえば、RSピンがLOWに設定されている場合、LCDにコマンドを送信しています（カーソルを特定の場所に設定する、ディスプレイをクリアする、ディスプレイを右にスクロールするなど）。そして、RSピンがHIGHに設定されている場合、LCDにデータ/文字を送信しています。

R/W (Read/Write) ピンは、LCDからデータを読み取るか、LCDにデータを書き込むかを制御します。このLCDをOUTPUTデバイスとしてのみ使用するため、このピンをLOWに接続します。これにより、WRITEモードになります。

En (Enable) ピンはディスプレイを有効にするために使用されます。つまり、このピンがLOWに設定されている場合、LCDはR/W、RS、およびデータバスラインで何が起こっているかを気にしません。このピンがHIGHに設定されている場合、LCDは受信データを処理しています。

D0-D7 (Data Bus) は、ディスプレイに送信する8ビットデータを運ぶピンです。たとえば、ディスプレイに大文字の「A」を表示したい場合、これらのピンを0100 0001（ASCIIテーブルに従って）に設定してLCDに送信します。

A-C (Anode & Cathode) ピンはLCDのバックライトを制御するために使用されます。

**接続図**

LCDディスプレイをArduinoに接続しましょう。LCDからの4つのデータピン（D4-D7）は、Arduinoのデジタルピン\##4-7に接続されます。LCDのEnableピンはArduino \##2に接続され、LCDのRSピンはArduino \##1に接続されます。
